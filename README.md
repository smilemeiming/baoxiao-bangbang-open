# 发票识别与报销管理工具｜报销帮帮

**发票识别、发票归档与报销报表，一处完成。**

报销帮帮是一款以发票识别为核心的报销管理工具。导入图片或 PDF 后，它会读取票面文字、提取金额和日期等信息，帮助你分类、核对并生成 Excel 报表，减少手工录入和整理附件的工作。

项目提供 **Windows 桌面版**和**微信小程序源码**。希望下载后直接使用的朋友，请选择 Windows 程序包；小程序适合希望自行部署和继续开发的人。

![Windows 桌面版发票库，画面中的票据均为虚构测试数据](docs/images/desktop-library.png)

## 下载后怎样使用

### 下载入口与当前状态

请先查看 [GitHub Releases](https://github.com/smilemeiming/baoxiao-bangbang-open/releases) 是否提供 `BaoxiaoBangbang-0.1.1-win-x64.zip` 附件；如果没有程序包，请向维护者获取。GitHub 的 `Code → Download ZIP` 和 Releases 自动生成的 `Source code` 都是源码，不能解压后直接运行 Windows 应用。

Windows 程序只会在版本页面附带完整 ZIP 时可直接下载。GitHub 自动生成的源码包不包含可运行桌面应用所需的打包环境。

### 第一次使用

1. 将 Windows 程序 ZIP **全部解压**到一个普通文件夹，不要在压缩包窗口中直接运行。
2. 打开文件夹中的 `BaoxiaoBangbang.exe`，保留旁边的文件和子目录。
3. 点击右上角“＋ 导入发票”，选择 JPG、JPEG、PNG 或 PDF，也可以把文件拖入窗口。
4. 点击导入后的记录，对照左边原件核对金额、日期、商家、票号和费用类别。
5. 勾选“字段已核对，允许计入报表”，点击“保存记录”。每张导入记录最初都是“待核对”。
6. 在底部选择报表类型，点击“导出 Excel”，选择保存位置。
7. 如需按一次报销整理附件，勾选相关记录创建批次，再导出含 Excel 和去重原件的 ZIP 资料包。
8. 完成整理后点击“备份数据”，另存一份包含原件的备份。

使用打包好的 Windows 程序时，不需要安装微信、Node.js、Python，也不需要注册账号、填写 API 密钥或首次联网下载模型。阅读 [完整使用手册](docs/USER_GUIDE.md)，可查看逐步操作、报表范围、备份迁移和常见问题。

## 能帮你做什么

- **导入并读取票据**：电子 PDF 优先读取文字；扫描 PDF 和图片使用本机中英文 OCR。多页 PDF 按页形成记录。
- **核对与整理**：对照原件修改商家、金额、日期、票号、购销方信息、分类、承担部门和备注；也支持手动新增记录。
- **本地归档**：导入时复制原件；支持预览、按文件内容去重，以及另存规范命名的原件副本。
- **查找和管理**：按待核对、已核对、费用类别查看，搜索商家、票号或文件名，批量删除并撤销最近一次删除。
- **中断后继续**：多页 PDF 已处理页会保留；再次导入同一文件时继续遗漏页面，识别失败的空白页可以重试。
- **重复提示**：相同销售方与发票号码的记录会标为“疑似重复”，由使用者对照原件确认。
- **生成 Excel**：提供汇总表、明细表、按费用分类、住宿与餐补四种报表模式，默认只包含已核对记录。
- **导出范围清晰**：可选全部记录、当前筛选或所选记录；导出前显示符合核对状态和报表类型的记录数及金额。
- **按报销批次整理**：将已选择的记录归集为批次，按报表类型与核对状态导出 Excel 和去重原件 ZIP；删除批次不会删除记录或原件。
- **备份和迁移**：导出包含记录及原件的 JSON 备份，在另一台 Windows 电脑上先验证再合并恢复；验证失败不会留下半套发票记录。
- **损坏库恢复**：启动时发现发票库不可读取，可选择有效备份重建；原损坏目录会保留，备份验证失败不会替换它。

## 使用前需要了解

- Windows 版支持 Windows 10/11 **x64**；当前未提供 macOS、Linux 或 Windows ARM 原生包。预览版暂未代码签名，获取程序时请核对来源和校验值，不要关闭系统安全保护。
- 支持单文件不超过 **80 MB**、单份 PDF 不超过 **500 页**。模糊、倾斜、复杂表格、跨页票据或一页多张票据，可能需要人工补全和整理。
- OCR 结果需要逐项核对。显示的识别置信度不能代表金额、税号或票号一定正确，也不替代财务审核和发票真伪查验。
- 内容完全相同的文件会去重；同一张票的不同照片、截图或重新生成的 PDF，仍可能形成重复记录。
- 报表可以选择全部记录、当前搜索/侧栏筛选结果或表格已勾选记录；默认是全部记录。导出前会显示预计张数和金额。详见 [报表说明](docs/USER_GUIDE.md#五导出-excel-报表)。
- Windows 版没有账号、跨设备自动同步、多人审批或自动更新。小程序云识别的数据流与桌面版不同，详见 [隐私与数据保存](docs/USER_GUIDE.md#八数据保存与隐私)。

## 下载源码后运行

这部分供开发者使用。**Windows 普通使用者不需要执行命令。** 两个版本共用部分业务模块，请下载整个仓库，保留目录结构。

### 运行或构建 Windows 版

准备 Node.js **22.16 或更新版本**，在项目根目录打开终端，然后执行：

```sh
cd desktop
npm ci
npm run prepare:assets
npm test
npm start
```

构建可分发的 Windows ZIP：

```sh
npm run dist
```

首次安装和构建需要网络，输出位于 `desktop/dist/`。具体步骤见 [桌面版开发说明](desktop/README.md)。

### 体验或部署微信小程序

准备 Node.js 22.16 或更新版本和微信开发者工具，在项目根目录执行：

```sh
npm ci
npm run setup
npm run verify
```

在微信开发者工具中导入项目。公共 AppID 默认是 `touristappid`，工具要求时请填写自己的 AppID。切换到“总览”，点击“载入虚构示例数据”，即可体验分类、编辑和报表；示例没有图片或 PDF 原件，不能验证真实识别和原件操作。

启用真实云识别时，在自行生成的 `config.local.js` 填写自己的云环境，配置 AppID 并部署云函数。OCR 地址和令牌放在云函数环境变量中。完整步骤见 [部署指南](docs/DEPLOYMENT.md)和 [云函数说明](cloudfunctions/invoice-ocr/README.md)。
