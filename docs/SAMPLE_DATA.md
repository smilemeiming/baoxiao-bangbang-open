# 示例与回归数据

公开版本使用 `utils/mock-data.js` 中的虚构字段记录，不包含图片或 PDF。界面标记为示例，不能用于报销或发票查验。

发布准备将测试中的具体个人姓名、企业、原始票号、税号和地址替换为测试值，保留字段长度、OCR 混淆字符和跨行结构以覆盖相同解析问题。

原工作目录 `sample-invoices` 内所有文件均不进入候选版本；没有将这些图片的真实性、来源和授权视为已验证。旧 Python 样例生成脚本也不公开。

示例中的一组打车配对只用于历史回归；真实导入拒绝非航空行程单。贡献回归样例时请人工编造文本，不要复制真实身份、地址、税号或票号。媒体样例须提供来源、生成方法和可分发授权。
