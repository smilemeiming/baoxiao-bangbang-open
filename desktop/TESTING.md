# 验证范围

## 单元与文件测试

`npm test` 检查原件副本、内容去重、识别字段、失败时不读取文件名金额、核对状态、金额验证、持久化、Excel 导出范围、删除恢复、失败时无部分备份数据、损坏库恢复、批次备份和资料包原件去重。

## 实际 Electron 运行验证

维护者使用自行生成的虚构 PNG、两页电子 PDF 和扫描 PDF，通过真实页面导入流程执行本地 OCR、PDF 提取、详情预览和 Excel 导出。测试数据不得来自真实票据。

开发版及打包版均可使用受控的诊断入口：同时设置 `BAOXIAO_SMOKE_TEST=1`、`BAOXIAO_TEST_DATA=独立测试目录` 和 `BAOXIAO_SMOKE_FIXTURES=虚构票据目录`。目录内需有 `synthetic-invoice.png`、`synthetic-text.pdf` 和 `synthetic-scan.pdf`；诊断期望四条票据记录、金额分别为 108、108、66、108，日期为 2026-06-18，票号为 24442000000012345678，销售方为测试办公用品有限公司。

诊断输出 JSON、截图和测试报表到指定测试票据目录。测试目录应使用新目录，不能指向实际发票库。不设置上述变量时，应用使用普通运行流程，不会自动导入任何数据。

识别测试只证明这些虚构样例可跑通，不能证明所有中文发票或模糊扫描件的准确率。模型结果默认待核对。

## Windows 环境说明

本机受限开发环境会给执行目录附加特定 AppContainer 访问项，与 Electron 45 的安装目录检查冲突。验证应在正常解压目录启动，不关闭沙箱，不修改全局或项目目录的访问权限。目录权限的异常属于开发环境条件，并不通过降低应用沙箱设置来处理。
