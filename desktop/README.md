# 发票识别与报销管理工具 | 报销帮帮 Windows 桌面版

这是独立的 Windows 应用。使用者不需要微信开发者工具、Node.js、Python、OCR API 密钥或云环境。

普通使用者请先阅读 [完整使用手册](../docs/USER_GUIDE.md)，其中说明下载位置、界面操作、报表范围、原件导出、备份迁移和常见问题。[逐文件说明](../docs/FILE_GUIDE.md)解释源码和程序包中各文件的用途。

发布状态以 [GitHub Releases](https://github.com/smilemeiming/baoxiao-bangbang-open/releases) 页面上的版本附件为准。只有完整的 `BaoxiaoBangbang-0.1.1-win-x64.zip` 才能解压后运行；仓库源码 ZIP 不等于 Windows 程序包。

## 使用打包版本

1. 下载 `BaoxiaoBangbang-0.1.1-win-x64.zip`，解压整个压缩包。
2. 打开解压目录内的 `BaoxiaoBangbang.exe`。不要只复制单独的 exe；旁边的运行文件和模型也是应用的一部分。
3. 拖入 JPG、PNG 或 PDF，也可点击“导入发票”。
4. 打开记录，核对金额、日期、商家和票号，勾选“字段已核对”并保存。
5. 选择报表类型，导出 Excel。默认只导出已核对记录。
6. 勾选同一次报销的记录，创建报销批次；选中批次后可将 Excel 和去重后的原件导出为 ZIP。

支持 Windows 10/11 x64。应用暂未进行代码签名；下载发布版时应核对发行方及公布的 SHA-256，不应为运行本项目关闭系统安全保护。

## 本地识别

电子 PDF 优先提取文本；没有可用文字的 PDF 页面和图片使用内置 Tesseract.js 中英文模型。PDF 按页形成记录，单份最多 500 页；单文件最大 80 MB。所有记录默认待核对，不宣称模型结果已经通过财务审核。

模型、PDF 引擎和运行环境随包附带，首次运行也不需要下载模型。应用不接入在线 OCR，不需要配置密钥。扫描模糊、倾斜、复杂表格、票据跨页或一页包含多张票据时，可能需要手动补全、调整或删除多余记录。

## 文件与备份

- 导入复制原件，源文件保持原样。相同文件内容会去重。
- 多页 PDF 中断后可重新导入：已完成页跳过，遗漏页继续处理；未人工编辑的失败页可以重试。
- 记录和原件保存在应用的用户数据目录；左下角可直接打开。
- “导出规范命名原件”另存副本。多页 PDF 保留整份文件，不会按记录拆页。
- 删除记录不删除归档原件，可以撤销最近一次删除，重启后也有效。
- 只保留最近一批删除的撤销记录。报表可选全库、当前筛选或已勾选记录；默认全库，导出前显示符合核对状态和报表模式的条数及金额。
- “备份数据”生成包含原件的 JSON 备份；恢复入口在左下角。恢复前先验证备份并在临时数据中合并，全部成功后一次写入发票库；已有记录会跳过。备份含票据内容，请妥善保存。
- 批次只负责归集发票，不移动或删除记录。批次资料包按当前报表类型和核对状态生成 Excel，并将同一归档原件只加入一次；多页 PDF 仍作为完整文件。
- 如果发票库损坏导致启动失败，可在启动对话框选择备份恢复。成功后旧数据目录会改名保留；恢复失败时不会替换旧目录。

## 开发与构建

需要 Node.js 22.16 或更新版本。首次安装开发依赖需要网络。

```sh
cd desktop
npm ci
npm run prepare:assets
npm test
npm start
npm run dist
```

若开发环境设置了 `ignore-scripts=true`，需要允许 Electron 的官方安装脚本下载运行环境，或显式运行 `node node_modules/electron/install.js`。打包后使用者不需要上述步骤。

输出目录：`desktop/dist`。请完整保留模型、依赖许可证与共享业务模块。桌面版复用根目录分类、字段解析和 Excel 模块，因此从源代码构建时需下载整个仓库。

根目录的 `npm run prepare:release` 输出可供发布的源码副本，不等于 Windows 可执行应用包。Windows 应用通过本目录的 `npm run dist` 生成。
